Implemented Features
VLAN Segmentation
The network is divided into separate VLANs to improve security and network performance.

Inter-VLAN Routing
A Layer 3 switch provides communication between VLANs through Switch Virtual Interfaces (SVIs).

EtherChannel
LACP EtherChannel was implemented between switches to provide:

Redundancy
Increased bandwidth
Improved availability
Trunking
Trunk links were configured using IEEE 802.1Q.
